# Meals App

## Description

**Meals App** is a cross-platform mobile application built with **Flutter**. It allows users to search for meals, explore various recipes, and view detailed meal instructions. The app integrates with TheMealDB API to provide a vast collection of meal recipes along with essential details like ingredients, instructions, and nutritional values.

The app aims to be a convenient tool for food enthusiasts, cooking beginners, and anyone looking for meal inspiration.

## Features

- **Meal Search**: Search for meals by name, category, or ingredient.
- **Meal Categories**: Browse meals based on their categories (e.g., breakfast, lunch, dinner, dessert, etc.).
- **Detailed Meal Information**: View ingredients, step-by-step cooking instructions, and nutritional information.
- **Favorites**: Save your favorite meals for quick access later.
- **Responsive Design**: Fully optimized for different screen sizes, ensuring a smooth experience on both phones and tablets.

## Installation

### Prerequisites

Before running the app, ensure that you have **Flutter** and **Dart** installed. You can follow the installation guide here: [Flutter Installation](https://flutter.dev/docs/get-started/install).

### Steps to Run the App

1. **Clone the repository**:
   Open your terminal and clone the repository using:
   ```bash
   git clone https://github.com/Karthik1772/Meals_App.git
   ```

2. **Navigate to the project directory**:
   Change into the project directory:
   ```bash
   cd Meals_App
   ```

3. **Install dependencies**:
   Run the following command to fetch all the required dependencies:
   ```bash
   flutter pub get
   ```

4. **Run the app**:
   Launch the app on an emulator or a connected device with:
   ```bash
   flutter run
   ```
